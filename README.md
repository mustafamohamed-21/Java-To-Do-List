# Java Desktop To-Do List 📝

A comprehensive GUI task management application built with Java Swing and AWT. This project demonstrates object-oriented programming (OOP) principles and file I/O operations for persistent data storage.

## ✨ Features
* **Dynamic Task Management:** Add, delete, and track the completion status of tasks effortlessly.
* **Persistent Storage:** Automatically saves tasks to a local `Output.txt` file using `FileWriter` and `BufferedReader` so data is never lost.
* **Intuitive GUI:** Clean and responsive user interface designed with Java Swing components.

## 🛠️ Technologies & Tools
* **Programming Language:** Java
* **UI Framework:** Java Swing & AWT
* **Core Concepts:** Object-Oriented Programming (OOP), File Handling (I/O)
* **Version Control:** Git & GitHub
